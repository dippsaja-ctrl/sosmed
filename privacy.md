Kebijakan Privasi (Privacy Policy) - Multi-Sosmed Poster

Terakhir Diperbarui: 16 Oktober 2026
Selamat datang di Multi-Sosmed Poster. Kami berkomitmen untuk melindungi data pribadi Anda dan memastikan keamanan informasi yang Anda berikan saat menggunakan aplikasi kami. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan menjaga informasi Anda untuk keperluan posting konten ke media sosial.

1. Informasi yang Kami Kumpulkan

Aplikasi ini hanya mengumpulkan data yang diperlukan untuk menghubungkan dan mengirimkan konten ke akun media sosial kantor Anda:
• Informasi Akun Pengguna: Alamat email dan kata sandi saat Anda mendaftar di web internal kami.
• Token Akses Media Sosial (OAuth Tokens): Kunci akses digital (Access Token dan Refresh Token) dari platform pihak ketiga seperti Facebook, Instagram, TikTok, dan YouTube untuk memberikan izin posting atas nama akun kantor.
• Konten Postingan: Foto, video, teks caption, judul, dan tag yang Anda unggah ke aplikasi kami untuk dijadwalkan atau langsung diposting.

2. Bagaimana Kami Menggunakan Informasi Anda

Kami hanya menggunakan informasi Anda untuk:
• Mengautentikasi login Anda ke dasbor internal aplikasi.
• Mengirimkan, menerbitkan, dan menjadwalkan konten media sosial ke platform pilihan Anda (Facebook, Instagram, TikTok, YouTube) sesuai dengan perintah Anda.
• Memperbarui kunci akses secara otomatis (refresh token) agar koneksi akun tidak terputus.

3. Penyimpanan dan Keamanan Data

Keamanan data Anda adalah prioritas utama kami:
• Enkripsi Kunci Akses: Semua access token dan refresh token media sosial disimpan dalam database kami dengan metode enkripsi yang kuat (encrypted cast).
• Penyimpanan Lokal: Aplikasi ini digunakan untuk skala internal kantor, sehingga data tidak dibagikan atau dijual kepada pihak ketiga mana pun di luar organisasi.
• Retensi Media: File foto atau video yang diunggah untuk penjadwalan akan dihapus dari server kami setelah konten tersebut berhasil diterbitkan atau dibatalkan.

4. Hak Akses dan Memutuskan Koneksi

Pengguna memiliki kontrol penuh atas akun media sosial yang terhubung. Anda dapat memutuskan koneksi (Disconnect) kapan saja melalui menu "Akun Sosmed" di dalam aplikasi. Tindakan ini akan menghapus seluruh token akses yang tersimpan di database kami secara permanen.

5. Hubungi Kami

Jika Anda memiliki pertanyaan mengenai Kebijakan Privasi ini atau penggunaan aplikasi internal kami, Anda dapat menghubungi tim administrator IT kantor.
